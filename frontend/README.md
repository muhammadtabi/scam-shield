# Scam Shield Frontend

React and Vite dashboard for Scam Shield.

## Features

- Real-time detection interface for emails, SMS, and URLs
- Gmail inbox monitoring and sync
- Detection logs with severity filtering and search
- PDF and CSV report downloads
- Dark and light theme toggle

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
